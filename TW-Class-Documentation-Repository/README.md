# TW Class Documentation Repository

A compact collection of documentation pages prepared for the Technical Writing (TW) class. It records the main concepts and practical examples learned in **LaTeX, Beamer, Doxygen, Google Docs, Git and GitHub**.

## Repository contents

| Folder | What it contains |
|---|---|
| `Latex/` | LaTeX basics, mathematics, tables, image insertion, colours, article and report examples |
| `Beamer/` | Basics of creating presentation slides with Beamer |
| `Doxygen/` | Doxygen introduction, comment syntax, workflow, configuration and a small documented C++ example |
| `GoogleDocs/` | Uses and collaboration features of Google Docs |
| `Git-and-GitHub/` | Version control concepts, Git commands, GitHub workflow, branches and collaboration |

## How to use this repository

1. Open each folder and read its `README.md`.
2. Try the sample `.tex` files in an online LaTeX editor or a local LaTeX installation.
3. Generate Doxygen documentation by following the instructions in `Doxygen/README.md`.
4. Practise the commands in `Git-and-GitHub/GIT_COMMANDS.md` inside a test folder or repository.

## Learning objective

The aim is to understand how to prepare technical documents, presentations and code documentation, and how to maintain and share project work using version control.

## Note

The Git and Doxygen notes are based on the lecture PDFs supplied for this assignment. LaTeX and Beamer examples are concise practice examples covering the topics specified in the assignment.
