# Google Docs

Google Docs is a cloud-based word processor in Google Workspace. It is mainly used to create, edit, store and share documents online.

## Why is Google Docs used?

- **Real-time collaboration:** several people can work on the same document and see changes as they happen.
- **Easy sharing:** invite people by email or link and assign viewer, commenter or editor access.
- **Feedback and review:** comments and Suggesting mode make it easier to review and propose edits.
- **Automatic saving:** changes are saved online; version history helps view or restore earlier versions.
- **Accessible documents:** work from supported devices through a browser or app.
- **Document organisation:** headings and styles help structure content and create a table of contents.
- **Export and integration:** download as PDF, DOCX and other formats, and work with Google Drive and other Workspace tools.

## When is it useful?

Google Docs is suitable for group assignments, meeting notes, proposals, reports, shared plans and documents that need feedback from multiple people. It is less focused on automatically extracting API documentation from source code; that is a use case for Doxygen.

## Good practice

Use clear headings, consistent styles and meaningful file names. Share only with the required people, choose suitable access permissions, resolve comments after review, and check version history for important milestones.
